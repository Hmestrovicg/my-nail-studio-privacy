# My Nail Studio privacy policy

Public privacy policy for the Android game My Nail Studio by NineDudeGames.

Published at: https://hmestrovicg.github.io/my-nail-studio-privacy/

The page is plain HTML and CSS with no JavaScript, analytics, external fonts or build dependencies.
GitHub Pages serves the root of the `main` branch. Edit `index.html` to update the policy and its date.

The initial policy describes Android release 0.1.0, including disabled production ad requests and purchases.
Update the policy before enabling materially different data handling. Confirm that Google Play's Data safety
declarations and the app's privacy link match the actual version submitted for review.
